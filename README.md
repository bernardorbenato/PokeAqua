# PokeAqua

Aplicação web de produtos e pedidos, desenvolvida como projeto acadêmico utilizando HTML, CSS, JavaScript e banco de dados.

## Sobre o projeto

O PokeAqua é uma aplicação web voltada para apresentação de produtos e realização de pedidos. O projeto foi desenvolvido para praticar desenvolvimento de interfaces, lógica de programação e integração com banco de dados.

## Funcionalidades

- Visualização de produtos
- Organização de produtos por categorias
- Carrinho de compras
- Fluxo de pedidos
- Interface web
- Funcionalidades relacionadas a usuários e produtos

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- SQL/MySQL

## Estrutura do projeto

O projeto contém páginas HTML, arquivos CSS e JavaScript, além de recursos relacionados ao banco de dados.

## Como executar

1. Clone este repositório:

```bash
git clone https://github.com/bernardorbenato/PokeAqua.git
```

2. Abra a pasta do projeto.
3. Execute a aplicação conforme a estrutura disponível no repositório.

Caso seja necessário utilizar o banco de dados, consulte o arquivo `database.sql` para identificar a estrutura disponibilizada pelo projeto.

## Objetivo acadêmico

Projeto desenvolvido durante a formação acadêmica para praticar desenvolvimento web, lógica de programação e conceitos de banco de dados.
